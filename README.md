# Partner-Signion

SIGNION 파트너 관리자 (KT 외국인 휴대폰 개통) 화면 프로토타입 v0.2

- `index.html` — 단일 파일 프로토타입 (서버 불필요, 브라우저로 바로 열림)
- `assets/` — SIGNION 로고 원본 SVG (BI 가이드라인 기준)
- `backoffice/` — 내부 관리자(SIGNION BackOffice) 프로토타입. 대리점별 계약 · 요금 설정, 사용량, 확장팩 이력, 월 정산 · 마감, 공통 서버 집계 화면 포함 (`backoffice/README.md`, 개발 명세 `backoffice/DEVELOPERS.md`)

근거: 「SIGNION 파트너 관리자 기획서 v0.1」 (화면 A1~F2, 관리자 위계 4단계) · 「KT 통합 Admin 정책 — 대리점별 이용량·과금 관리」의 **고객사 어드민** 범위 · 디자인: SIGNION BI 가이드 (BackOffice와 공용 디자인 시스템)

- 로그인: 하단 「데모 계정」 버튼(헤드마스터 · 마스터 · 총괄 · 서브)을 누른 뒤 다음 → 인증
- 상단 「보기 권한」으로 위계별 메뉴·조회 범위를 바꿔 볼 수 있습니다 (프로토타입 전용)
- 「이용 현황」 하단의 「한도 시나리오」로 용량 경고 · 초과 차단 · 처리 한도 도달 · 확장팩 해제 흐름을 확인할 수 있습니다 (프로토타입 전용)
- 모든 이름·번호·건수·금액은 예시 데이터입니다.

## v0.2 변경 (KT 통합 Admin 정책 반영)

| 정책 항목 | 화면 |
| --- | --- |
| C1·C2 통합 | 「인증 결과」 메뉴 하나로 통합, 건 선택 시 고객 상세. 실패 건은 오류코드별 실패 사유 · 조치 안내 · 인증료 청구 대상 여부 표시 |
| C3 여권인증 | 「서비스 › 여권인증」 독립 메뉴. 마스터 · 총괄 · 서브 모두 사용, KT 헤드마스터는 비활성. 인증한 관리자가 담당자로 지정 |
| C4 미리보기 삭제 · 발급 이동 | 「제출 서류 발급」 독립 메뉴 제거(`#/issue/…`는 고객 상세로 이동). 고객 상세 안 「제출서류 PDF 발급」 카드에서 병합 순서 · 파일명 확인 후 바로 발급, 미리보기 없음 |
| 데이터 접근 범위 | 서브: 본인 담당 고객 / 총괄: 본인 + 소속 서브 / 마스터: 대리점 전체 / KT 헤드마스터: 전체 대리점. 메뉴 · 기능은 동일 |
| 계약 · 요금 | 대리점 ID별 계약기간 · 월 기본료 · 인증 단가 · 월 최소료 · 기본 계정 수 · 추가 단가 · 문서/보관 한도 · 확장팩 조건 (읽기 전용) |
| 이용 현황 | 문서 업로드 · 재업로드 · 다운로드 건수와 잔여, 동시 보관 용량과 잔여, 확장팩 수량, 필요 팩 산정, 신청 이력, 처리 · 용량 증감 이벤트 |
| 문서 처리 집계 · 한도 | 성공한 업로드 · 재업로드 · 다운로드(PDF 발급 포함) 각 1건. 보관 용량 초과 시 업로드 · 다운로드 차단, 월 처리 한도 도달 시 추가 처리 제한. 개통 완료 삭제 시 용량 차감 |
| 알림 | 보관 용량 잔여 10% 경고 배너 — 마스터에게는 확장팩 신청 버튼, 하위 관리자에게는 마스터 요청 안내. 초과 · 한도 도달 시 차단 안내 |
| 확장팩 | 마스터 직접 신청 → 즉시 한도 확대 · 차단 해제 · 신청 월 전액 과금. 승인 절차 · 자동 구매 없음 |
| 계정 | 마스터가 총괄 · 서브 생성 · 중지 · 삭제. 기본 제공 / 유료 추가 구분, 유료 추가 생성 시 과금 안내 팝업(정책 문구) → 확인 일시 · 확인자 기록. 당월 최초 고객정보 · 문서 조회/처리 시 과금, 사용 후 삭제 · 중지해도 과금 유지 |
| 월 이용료 | 대리점별 월 정산서 — 필수 2항목(기본료 · 여권인증 사용료) 매월, 선택 항목(추가 총괄 · 추가 서브 · 확장팩)은 발생 시에만. MAX(건수×단가, 최소료) 적용 표시, 공급가액 · VAT · 합계, 정산서 내려받기(CSV) |
| 개인정보 보관 | 클라우드에만 저장, 미개통 최대 2개월(60일) |

내부 어드민(로드시스템: 대리점별 설정 · 변경 이력 · 월 마감/정정)과 공통 서버 항목은 이 저장소 범위가 아닙니다. 화면은 그 설정값을 읽기 전용으로 받는다고 가정합니다.

## 확인이 필요한 정책 (프로토타입에서 임의로 정한 부분)

- **확장팩 적용 기간** — 신청 월에만 한도에 더한다고 가정했습니다(다음 달은 다시 신청). 계속 유지되는지 확인 필요.
- **유료 추가 계정 판정** — 생성 시점의 같은 위계 계정 수가 기본 제공 수 이상이면 유료로 정했습니다. 기본 계정을 지운 뒤 기존 유료 계정이 기본으로 바뀌는지는 정하지 않았습니다.
- **총괄 관리자의 계정 관리** — 정책상 마스터만 생성 · 중지 · 삭제하므로 총괄의 「계정 관리」 메뉴를 뺐습니다(v0.1에서는 서브 발급 가능).
- **계약 · 요금 / 월 이용료 노출 범위** — 마스터와 KT 헤드마스터만 보게 했습니다. 총괄 · 서브는 「이용 현황」만 봅니다.
