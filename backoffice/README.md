# signion-backoffice

SIGNION BackOffice 관리자 화면 프로토타입 (v0.2)

- `index.html` — 단일 파일 프로토타입 (서버 불필요, 브라우저로 바로 열림)
- `assets/` — SIGNION 로고 원본 SVG (BI 가이드라인 기준)

메뉴 구성은 `backOffice관리자_메뉴구성도.xlsx` 기준이며, 화면의 고객·거래 데이터는 모두 프로토타입용 가상 데이터입니다.
로그인 화면에서는 아무 값이나 입력하면 진입합니다.

## 대리점 이용 · 과금 (KT 통합 Admin 정책 — 내부 어드민 · 공통 서버)

고객사(파트너) 어드민 화면은 이 저장소 루트(`../index.html`)에 있고, 여기에는 그 설정값과 집계를 만드는 내부 어드민 쪽을 둡니다.

| 메뉴 | 내용 |
| --- | --- |
| 대리점 과금관리 › 계약 · 요금 설정 | 대리점 ID별 계약기간 · 월 기본료 · 인증 단가 · 월 최소료 · 기본 계정 수(마스터 · 총괄 · 서브) · 추가 계정 단가 · 문서 월 한도 · 동시 보관 용량 · 확장팩 조건. 등록 · 수정 시 입력 검사, 저장 즉시 변경 이력 + 고객사 반영 |
| › 설정 변경 이력 | 항목별 변경 전/후 · 작업자 · 적용 시점 · 고객사 반영 결과 (수정 · 삭제 불가) |
| › 사용량 조회 | 대리점별 · 월별 업로드 · 재업로드 · 다운로드, 동시 보관 용량, 외부 송신량(참고용 · 과금 제외), 계정 · 확장팩 수, 한도 상태. 엑셀 내보내기 |
| › 확장팩 적용 이력 | 고객사 마스터 신청 → 즉시 적용된 수량 · 적용일 · 추가 한도 · 청구월 (내부 승인 없음) |
| › 월 정산 · 마감 | 설정 단가 × 이용 실적으로 기본료 · 여권인증료(MAX(건수×단가, 최소료)) · 추가 계정료 · 확장팩료 산정, 공급가액 · VAT · 합계. 필수 2개 항목은 매월, 선택 항목은 발생 시에만. 「월 마감 확정」(설정값 스냅샷 고정) · 「정정」(사유 · 조정액) · 「정산서 다운로드」 |
| 공통 서버 집계 › 문서 처리 이벤트 · 보관 용량 증감 · 여권인증 청구 집계 · 유료 계정 최초 이용 · 한도 이벤트 · 개인정보 자동 삭제 · 백업 · 복구 | 과금 근거 이벤트 로그 (원본 문서 · 여권정보는 기록하지 않음) |

- 과금 근거 이력(설정 변경 이력 · 월 정산 · 유료 계정 최초 이용)은 SysAdmin · 운영 관리자만 볼 수 있게 권한을 나눴습니다.
- 「작업관리 › 권한관리」 · 「개발 명세」 · `DEVELOPERS.md`에 새 화면의 권한 코드 · 필드 · API 초안이 자동으로 들어갑니다.
- 메뉴가 늘어나 「인증수수료관리」 뒤 화면들의 프로그램ID 번호가 밀렸습니다 (PKD관리 013 → 025 등).
- 백업 주기 · 보관기간과 개인정보 삭제 정책의 정합성은 정책서대로 기술팀 설계 항목으로 남겨 두었습니다.
